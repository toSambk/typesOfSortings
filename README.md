# typesOfSortings

`typesOfSortings` is a small Java project with straightforward implementations of several classic sorting algorithms.

## Included Algorithms

- bubble sort
- counting sort
- insertion sort
- merge sort
- quick sort
- selection sort
- shell sort
- shuttle sort

## Project Structure

Each algorithm lives in its own package under `src/main/java` and is implemented as a standalone example class.

## Build

Compile the project with Maven:

```bash
mvn clean package
```

## Verification

You can verify the repository with:

```bash
mvn test
```
